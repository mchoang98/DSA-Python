# Giới thiệu Cấu trúc Dữ liệu & Giải thuật với Python

## 1. Tại sao học DSA?

Cấu trúc dữ liệu và thuật toán (DSA) là **nền tảng của lập trình hiệu quả**. Khi học DSA, bạn sẽ:

* Viết code **nhanh hơn và tiết kiệm bộ nhớ hơn**.
* Giải quyết các vấn đề phức tạp một cách có hệ thống.
* Chuẩn bị tốt cho **phỏng vấn kỹ thuật**.

---

## 2. Bạn sẽ học gì

* **Cấu trúc dữ liệu**: Mảng, danh sách liên kết, ngăn xếp, hàng đợi, bảng băm, cây, đồ thị.
* **Thuật toán**: Tìm kiếm, sắp xếp, đệ quy, chia để trị, tham lam, lập trình động.
* **Ứng dụng thực tế**: Giải bài toán, mini-project, thực hành trên Python.

---

## 3. Chuẩn bị

* **Python 3.10+**
* Trình soạn thảo: VS Code, PyCharm, hoặc Jupyter Notebook
* Thư viện hỗ trợ: `collections` (deque, Counter), `heapq` (min-heap)

---

## 4. Cách học

1. Bắt đầu từ **cơ bản**: mảng, danh sách, vòng lặp, hàm.
2. Thực hành từng **thuật toán và cấu trúc dữ liệu** bằng Python.
3. Luôn **phân tích độ phức tạp** để biết code nhanh hay chậm.
4. Làm **bài tập và mini-project** để áp dụng kiến thức.
